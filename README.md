# Sistema CRUD com JavaScript

Projeto desenvolvido para praticar os conceitos fundamentais de um sistema CRUD utilizando HTML, CSS e JavaScript.

CRUD é a sigla utilizada para representar as quatro operações básicas realizadas em sistemas de cadastro:

- Create — cadastrar dados;
- Read — consultar dados;
- Update — atualizar dados;
- Delete — excluir dados.

## Objetivo

O objetivo deste projeto foi desenvolver uma aplicação web simples para consolidar conhecimentos em desenvolvimento frontend, manipulação de formulários e lógica de programação com JavaScript.

## Funcionalidades

- Tela inicial;
- Cadastro de usuários;
- Tela de login;
- Validação básica dos campos;
- Manipulação de dados com JavaScript;
- Interface desenvolvida com HTML e CSS.

## Tecnologias utilizadas

- HTML5;
- CSS3;
- JavaScript.
